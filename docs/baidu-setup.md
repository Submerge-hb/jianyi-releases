# 轻语 0.6 · 百度翻译配置与验收

0.6.0-beta 已于2026-10-22公开发布，使用者确认联网翻译恢复正常。量化性能与完整质量矩阵仍可按本文继续验收。

## 1. 安装

将 qingyu-0.6.0-beta.apk 传到一加 12 并打开，按安卓提示覆盖安装。不要先卸载。包名和签名沿用旧版，收藏、历史和已安装语音包应保留。

## 2. 个人账号准备

在手机或电脑打开 [百度翻译开放平台](https://fanyi-api.baidu.com/)，登录个人账号，按平台要求完成个人认证并开通「通用文本翻译」高级版。认证材料只提交给百度官方。

在控制台核对：服务已开通、当前方案为高级版、本月免费额度及剩余字符。高级版官网当前列示每月 100 万免费字符，实际以你的账号为准：[官方定价与说明](https://api.fanyi.baidu.com/product/112)。不要为本次测试开启自动充值。余额为零不等于平台立即停服。

## 3. 在手机里配置

进入轻语「设置 → 翻译服务」：

1. 填写自己的 APP ID、密钥。密钥默认隐藏；配置页不允许截图，不会预填展示完整密钥。
2. 填写平台显示的「本月剩余免费字符」。如果平台显示总免费额度与本月已用量，请先相减再填写；无法确认时先不要启用联网。
3. 勾选已核对额度且同意向百度发送待译文字的说明，点「保存并启用」。
4. 点「测试连接」，会发送示例 I want to eat beef，保守计入本机用量。确认实际返回译文包含「我想吃牛肉」的完整意思，记录耗时。
5. 返回首页开始使用。无需向聊天发送 APP ID、完整密钥或身份材料。

每月首次调用前需要重新核对平台剩余额度并保存；同一个 APP ID 的密钥留空可保留原值。若更换账号，需填写新密钥。删除凭据、清空历史不会清掉用量账本。

本机每月默认最多 10 万字符；根据填写的剩余额度收紧，并预留 1000 字符缓冲。发送前预记，发送后取消、超时或服务失败仍保守计数。缓存、离线查词和朗读不计入。达到本机额度后暂停调用，缓存和离线词典仍可用。

这是本机估算，不是平台账单；同账号的其他设备调用、清除应用数据、重装及平台结算延迟都可能影响判断，不能保证绝对零费用。应用不会自动充值或切换付费方案。

## 4. 翻译验收

分别切换英译中和中译英，检查下列真实结果；不要仅凭「连接成功」判断翻译质量。

| 输入 | 核对要点 |
|---|---|
| I want to eat beef | 完整包含想吃牛肉，不漏 beef |
| I do not want to eat beef. | 保留否定 |
| Alice bought 12 books for $30. | 保留人名、12 和 30 美元 |
| The bank is near the school. I walk there every day. | 两句话均有译文 |
| 第一段：I want beef. 换行空一行后第二段：She wants tea.（仅输入英文两段） | 两段齐全、换行保留 |
| 他在银行工作，周末喜欢步行去公园。 | 银行和步行按上下文处理 |
| 这首音乐很好听。 | 音乐按上下文翻译 |

返回原文覆盖检查能拒绝缺段等异常，无法保证识别全部语义错误。旧 MyMemory 结果会标注「旧版已保存」，需要时点「重新联网翻译」。

首次有效译文保存后再次提交相同内容，应显示「百度翻译 · 已保存」且不增加用量。点「重新联网翻译」会重新发送并计数。修改大小写、标点、方向或段落应作为不同查询。

## 5. 一加 12 性能和交互

分别使用 Wi-Fi 与移动数据测试。短句首次联网 P95 ≤3 秒、缓存展示 ≤200 毫秒是待验证目标，不是已达到的结果。建议每种网络记录至少20条短句的实际等待时间，统计第95百分位；首次和缓存分别记录。

- 连续点击同一查询不应重复计数；输入改变后旧结果不得覆盖新查询。
- 开启飞行模式，查询 bank、计算机，打开已保存句子并离线朗读。
- 切换英美声音、后台返回、横竖屏，确认原有语音功能继续正常。
- 默认字号和系统大字号下查看首页标题、题句、输入框及底部导航，无裁字或遮挡。
- 检查收藏、历史和已安装语音包在覆盖安装后保留。

## 6. 更新页面

进入「设置 → 应用更新」。当前公开版本为0.6.0-beta；已安装本版本时不会重复提示更新，也不会降级安装。

始终可点「浏览器下载」打开同一官方仓库。证书错误会提示切换网络或使用浏览器，不会跳过 HTTPS 校验；GitHub 在部分网络下仍可能受限。技术详情可展开和复制，已去除原始异常 URL 等潜在敏感内容。

检查版本、下载和校验有各自状态；安装需安卓授权。测试不应通过卸载来解决覆盖安装问题，否则会丢失本机数据。
