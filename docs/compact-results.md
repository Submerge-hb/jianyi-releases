# 轻语 0.6.1 手机体验

覆盖安装 qingyu-0.6.1-beta.apk，无需先卸载。包名和签名沿用原版；不要安装 qingyu-tests.apk 或 qa-fixtures 下的安装包。

## 体验步骤
1. 默认字号、竖屏，查 judge、bank、I want to eat beef、这首音乐很好听。收起键盘后，查看紧凑输入、完整结果和底部操作是否同屏。
2. 单词页面检查所有词义与英美音标，分别试听。句子页面点按英文词语查义，试用底部英美朗读、复制、收藏。
3. 点击结果右侧「···」查看来源和重新联网翻译。修改输入后旧结果与操作栏应消失，清空后恢复山水首页。
4. 查看长句、多段文本和「行」的多个对应词；滑到末尾，确认最后一项没有被操作栏遮挡。
5. 在收藏、历史中重新打开内容，旋转屏幕或返回页面，确认内容保留且不会自动发起新请求。
6. 调整系统字体至较大和最大，确认内容可读、操作栏能换行。横屏与键盘打开时允许滑动，不能裁掉译文。
7. 有网络时检查百度翻译；断网时检查离线词典、缓存和朗读。网络等待时尝试取消、连续提交、修改输入，旧响应不应覆盖新输入。

模拟器验证记录见源码包内测试报告；截图中的百度译文使用模拟响应，仅验证布局与交互。
