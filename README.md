## 本次变化

- 单词和句子联网优先。首次同意后，点击翻译直接使用 MyMemory；设置可关闭联网翻译。输入过程中不发送。
- 断网、超时或服务失败时自动尝试本地词库与已保存译文。未保存的新句子需要联网，不会伪造离线翻译。
- 独立英美语音包，下载后在应用内合成英文单词和句子，不依赖系统 TTS。语音为本机模型合成，不是逐词真人录音。
- 首页增加网络状态和语音管理入口，简化宣传区；结果自动滚动到阅读位置，并可返回修改输入。
- 12,000 个离线词条、英美音标、主要释义、中文反查、词形、收藏与历史继续保留。

首页点「英美语音包」分别下载：英式约 80.5 MB（安装约 95 MB），美式约 67.2 MB（安装约 82 MB）。建议 Wi-Fi，预留至少 300 MB 安装空间；下载期间保持页面打开，取消后需重新下载。下载经过 HTTPS、大小和 SHA-256 校验。

## 应用内更新

0.3：右上角「离线 + 联网」→「检查更新」。

0.4：右上角「设置」→「检查更新」。

下载后点「安装更新」，首次按提示允许简译安装应用，再由 Android 确认。0.1 / 0.2 需要手动覆盖安装。没有后台定时检查或静默安装。GitHub 访问受网络影响，失败时可更换网络重试。

## 测试范围与限制

本轮模拟器累计通过 133 项检查，覆盖翻译、缓存、离线回退、两种语音合成和 Android 播放、更新包校验。安装包已从公开地址重新下载并核对哈希。

完整语音包联网下载在本次模拟器网络中遇到证书链验证失败，尚未验收；没有关闭 HTTPS 校验。模型通过本地测试夹具安装后，断网合成和播放验证通过。一加 12 实机的下载、实际听感和覆盖升级仍待确认。

开放词库来自 ECDICT、ipa-dict 等，不属于牛津授权词典，也不保证每个词义及音标已人工核对。中文多音字消歧依赖联网翻译上下文与服务质量。MyMemory 单次限制 500 UTF-8 字节，服务质量、额度与可用性由第三方决定；不要发送敏感文字。
