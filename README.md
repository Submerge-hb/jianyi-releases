## 安装与更新

已有旧版：进入「设置 → 检查更新」（0.6 及以上版本为「设置 → 应用更新」），下载并安装。也可用手机浏览器下载上面的 APK，按安卓提示直接覆盖安装。**不要先卸载**，以保留收藏、历史、已配置的翻译凭据和已安装语音包。

支持 Android 8.0 及以上，包含 ARM64 和 x86_64，沿用原包名和签名。下载名保留 jianyi- 以兼容旧版更新器，安装后名称为轻语。没有后台定时检查或静默安装。

## 首次使用联网翻译

**0.6 改用个人百度翻译接口，需在每台手机自行配置。安装包中没有公共或私人密钥。**

在[百度翻译开放平台](https://fanyi-api.baidu.com/)完成个人认证并开通通用文本翻译高级版，再进入「设置 → 翻译服务」填写自己的 APP ID、完整密钥和本月剩余免费字符，保存后测试连接。不要将密钥或身份材料发到 Issues。

[配置与验收说明](docs/baidu-setup.md)。未配置时仍可使用离线词库和已保存译文，不再自动调用 MyMemory。54001 表示请求签名校验失败，请检查配套的 APP ID 与完整密钥。

凭据通过 Android Keystore 加密保存在本机；翻译文字只在提交或测试连接时发送给百度。本机默认每月最多调用10万字符，并按填写的剩余额度收紧；每月重新核对。超时或发送后取消仍保守计入。缓存、离线查询和朗读不计入；删除凭据或清空历史不重置用量。

本机估算不是平台账单，不能约束同账号其他设备的调用，也不能保证绝对零费用。应用不自动充值或切换付费方案，平台权益以个人账号为准。
