## 安装与更新

已有旧版：打开应用的「设置 → 检查更新」，下载并安装新版。也可以用手机浏览器下载上面的 APK，按系统提示允许本次安装。直接覆盖安装即可保留收藏、历史和已安装的语音包；请勿先卸载旧版。

支持 Android 8.0 及以上，包含 ARM64 和 x86_64。沿用原应用标识和签名。下载文件名保留 `jianyi-`，以兼容旧版更新器；安装后的名称为「轻语」。仓库地址也保持不变。

## 本次更新

- 淡墨山水首页，以「字里行间，山海相逢。」替代冗余说明；精简标识和宣传卡片，查询后展示翻译结果。
- 英式语音更换为 **Cori medium**，美式声音保持原选择。安装新版后，在「设置 → 英美语音包」中选择「更新英式语音」（首次使用则下载英式包），下载量约 67.3 MB。新包安装成功后切换；失败或取消时仍保留旧声音。
- 英美朗读加入模型复用、后台预加载、最多 8 MiB 内存音频缓存和分段播放，减少重复加载与等待。
- 保持联网翻译优先、无网自动回退离线查询；语音包下载完成后可完全离线朗读。
