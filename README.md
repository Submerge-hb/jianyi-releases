# 简译 · Android
轻量中英双向查词与短句翻译，米白与柔和绿色界面。

## 下载 0.3.0 测试版
[下载安装包（约 2.74 MB）](https://raw.githubusercontent.com/Submerge-hb/jianyi-releases/b4314af3b98a178f2c9f649b2b23f3bd51398fb4/packages/jianyi-0.3.0-beta.apk)

需要 Android 8.0 或更新版本。已有旧版请直接覆盖安装，不要先卸载，以保留本机收藏和历史。初次安装请按手机提示允许当前下载来源安装应用。

## 后续在应用里更新
打开简译右上角「离线 + 联网」→「检查更新」→「下载新版」→「安装更新」。首次使用更新功能，按提示允许“简译”安装应用，返回后再次点击安装。安卓系统仍会要求确认。没有新版本时会显示当前已是最新版本。

0.1 / 0.2 需要先手动安装本次 0.3，之后便可在应用内获取已发布的新版。不会后台定时检查或静默安装。访问 GitHub 需要网络；连接失败可以稍后重试。

## 功能与范围
- 12,000 个离线词条，英美音标、中文释义、中文反查和常见词形。
- MyMemory 联网短句翻译，发送前确认文字；历史与收藏保存在手机。
- 系统离线语音发音，需手机具有相应语音引擎和语音包。
- 更新下载会校验大小、SHA-256、包名、版本与签名。

仍是个人测试版，使用开发签名。词库来源 ECDICT、ipa-dict 等开放数据，许可随 APK 提供，可在应用中查看；不属于牛津授权词典，未承诺完整收录或逐条人工校对。联网翻译质量和可用性取决于第三方服务。不要向第三方翻译服务发送敏感文字。

本仓库存放安装包与公开更新配置，不包含源代码或签名私钥。当前直接使用仓库文件发布，未创建 Releases 条目。
